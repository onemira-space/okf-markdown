okf-markdown

Open Knowledge Format (OKF v0.2) Validator, Link Graph Builder & Transcript CLI · MIT License · GitHub Repository

okf-markdown is a zero-dependency Node.js CLI and ESM package for local-first meeting and research vaults. It converts raw WebVTT (.vtt), SubRip (.srt), and speaker-labeled transcripts into deterministic OKF v0.2 Markdown files, validates YAML frontmatter schemas, and verifies relational [[wiki-links]] across folders.

CLI Usage

npx github:onemira-space/okf-markdown ingest ./meeting.vtt --title "Architecture Sync" --out ./vault/sessions/sync.md
npx github:onemira-space/okf-markdown validate ./vault
npx github:onemira-space/okf-markdown graph ./vault --out ./graph.json
